# Тысяча (1000) — веб-приложение для iPhone

Карточная игра «Тысяча» на троих: вы и два компьютерных соперника.
Работает в Safari и устанавливается на экран «Домой» как обычное приложение.

## Файлы
- `index.html`, `style.css` — интерфейс
- `engine.js` — правила и компьютерные соперники
- `app.js` — управление игрой, счёт, настройки, сохранение
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на iPhone и работа без интернета
- `serve.js` — локальный сервер для проверки

## Вариант 1. Через интернет (рекомендуется, работает офлайн)
1. Откройте https://app.netlify.com/drop и перетащите туда папку `Игра 1000`
   (или опубликуйте папку на GitHub Pages).
2. На iPhone откройте полученную ссылку в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запускайте иконку «Тысяча». После первого запуска игра работает без интернета.

## Вариант 2. По домашнему Wi-Fi
1. На компьютере: `node serve.js` в папке игры.
2. На iPhone (в той же сети Wi-Fi) откройте в Safari адрес `Network: http://...:8080` из консоли.
3. «Поделиться» → «На экран Домой».
   В этом варианте игра работает, только пока компьютер с сервером включён.

Игра сохраняется автоматически: можно закрыть приложение и продолжить с того же места.
